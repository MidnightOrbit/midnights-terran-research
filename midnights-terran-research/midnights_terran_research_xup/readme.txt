Midnight's Terran Research - XUP Compatibility  (v1.01, X4: Foundations 9.00+)
by Midnight

WHAT IT DOES
An add-on for Midnight's Terran Research. X4 Upgrade Project adds four HQ research items
(Ship Recycling Efficiency I-III and Ship Reverse Engineering); this makes them cost Terran
wares too, the same way the main mod does.

REQUIREMENTS
  - Midnight's Terran Research 1.05 or later
  - X4 Upgrade Project: https://www.nexusmods.com/x4foundations/mods/2447

Only install this if you use XUP: without it, the add-on does nothing. Safe to add or remove mid-game.
