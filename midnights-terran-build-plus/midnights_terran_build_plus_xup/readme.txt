Midnight's Terran Build Method Plus - XUP Compatibility  (v1.01, X4: Foundations 9.00+)
by Midnight

WHAT IT DOES
An add-on for Midnight's Terran Build Method Plus. X4 Upgrade Project adds its own
Commonwealth ships, weapons and turrets; this gives them Terran recipes too, the same way the
main mod does. Without it, a Terran wharf or shipyard still asks for hull parts and the other
Commonwealth wares for XUP's items.

REQUIREMENTS
  - Midnight's Terran Build Method Plus 1.01 or later
  - X4 Upgrade Project: https://www.nexusmods.com/x4foundations/mods/2447

Only install this if you use XUP: without it, the add-on does nothing. Safe to add or remove mid-game.
