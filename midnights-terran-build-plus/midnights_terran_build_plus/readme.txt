Midnight's Terran Build Method Plus  (v1.01, X4: Foundations 9.00+)
by Midnight

WHAT IT DOES
I play Terran, and I wanted my Terran stations to build everything with Terran wares. With
this mod, any station set to the Terran build method can build Commonwealth ships, station
modules and equipment from Terran wares instead of hull parts, claytronics and the rest.

It isn't a shortcut: the Terran versions cost a bit more in mined resources than the normal
ones (modules 1.05x, shields 1.10x, everything else 1.2x), and never less in credits.
Stations on any other build method build exactly like vanilla.

It covers 870 Commonwealth ships, station modules, engines, shields, turrets, weapons and
missiles, across the base game and every DLC you own. The Erlking keeps its normal recipe.

REQUIREMENTS
  - X4: Foundations 9.00 or later
  - Cradle of Humanity DLC (the Terran wares and the Terran build method come from it)

Using X4 Upgrade Project? Grab the optional add-on "Midnight's Terran Build Method Plus - XUP
Compatibility" as well, and XUP's ships and weapons get Terran recipes too.

HOW TO USE
Set the build method to Terran: Player Information > Global Orders > preferred build method,
or per station.

GOOD TO KNOW
  - Safe to add or remove mid-game. Finish or cancel builds that use its recipes first.
  - Don't run it with another mod that adds Terran recipes to Commonwealth items.

INSTALL
Subscribe on the Steam Workshop, or copy the folder into  X4 Foundations/extensions/  so you
have  extensions/midnights_terran_build_plus/content.xml
