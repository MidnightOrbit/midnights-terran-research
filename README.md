# Midnight's X4 Mods

My mods for X4: Foundations (game version 9.00+). Each one has its own folder with a README,
the mod itself, and any optional add-ons.

| Mod | What it does | Get it |
|---|---|---|
| [Midnight's Terran Research](midnights-terran-research/) | Player HQ research paid in Terran wares, at the same credit value | [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3846161649) · [Nexus](https://www.nexusmods.com/x4foundations/mods/2629) |
| [Midnight's Terran Build Method Plus](midnights-terran-build-plus/) | Terran-method stations build Commonwealth ships, modules and equipment from Terran wares | [Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3846306118) · [Nexus](https://www.nexusmods.com/x4foundations/mods/2630) |

Both need the **Cradle of Humanity** DLC. Optional X4 Upgrade Project add-ons are in each mod's folder.
